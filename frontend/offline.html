⚔️ Text Game RPG

Файл открыт напрямую из папки — без запуска игры.

Эта страница — только экран-подсказка. Сама игра — это сервер на Python: он ведёт мир, ходит в LLM, хранит базу в SQLite и отдаёт /api/*. Вкладка, открытая по file://, до этих endpoint'ов дотянуться не может, поэтому игру нужно запустить локально одним двойным щелчком:

  1. Закройте эту вкладку.
  2. Запустите файл start_game.bat в корне проекта
    D:\...\text_game\start_game.bat (двойной щелчок; движок llama.cpp на 8080 должен быть уже запущен)
  3. Откроется браузер на http://127.0.0.1:8002 — это и есть игра.
«Локальный сервер» здесь — не то, что нужно ставить отдельно: это и есть игра. Порт 8002 слушает только этот компьютер (127.0.0.1), наружу ничего не уходит.

Если нужен ярлык — создайте его на start_game.bat; при открытии страницы ещё раз покажется эта подсказка, т.к. index.html стучится на тот же адрес http://127.0.0.1:8002 и, не найдя его, предлагает запуск.
