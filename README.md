# ⚔️ Text Game RPG — живая текстовая RPG с ИИ-рассказчиком

> ## ⚠️ Внимание: проект написан ИИ-агентом
>
> **Весь этот код, документация и тесты созданы/поддерживаются языковой моделью (ИИ-агентом),
> а не человеком-инженером.** Это не «альфа» и не «демо» — рабочий проект, но в нём **возможны
> ошибки, недоработки, локально странные решения и устаревшие комментарии**. Мы находим и
> устраняем их по мере обнаружения (см. баг-ханты сессий в `AGENT.md`), но полностью
> гарантировать отсутствие дефектов — нельзя.
>
> **Практические следствия — читать до того, как что-то трогать:**
> 1. **Не доверяй коду вслепую.** Перед правкой сверяйся с `AGENT.md` (правила, три закона,
>    реестр известных багов) и с тестами; ИИ-код часто выглядит убедительнее, чем работает.
> 2. **Ничего не «чиним» молча.** Если нашёл баг — зафиксируй (пункт в баг-ханте + регресс
>    -тест), а не правь «по ходу дела»: иначе следующая ИИ-сессия про него не узнает.
> 3. **Ломать обратно легко.** ИИ-сессия, не прочитавшая `AGENT.md`, с высокой вероятностью
>    вернёт уже исправленный баг или нарушит архитектурный закон — поэтому файл обязан
>    оставаться актуальным.
> 4. **ИИ-генерация живёт в игре, а не в движке.** Ответы рассказчика, карточки, сводки —
>    текст модели: он может быть фактологически противоречивым; за согласованностью следит
>    фоновый «судья логики», но он не всемогущ.
>
> Итог: относятся к проекту как к **живому эксперименту с ИИ в роли мейнтейнера** — полезно,
> интересно, местами шероховато. Шероховатости находим и закрываем по мере сил.

Веб-приложение: открытый мир, управляемый ИИ-рассказчиком (сменные провайдеры: llama.cpp / Ollama / OpenAI-совместимый), с **гибридной долгосрочной памятью** (облачные эмбеддинги + локальная ChromaDB + сводки) и **персональными карточками сущностей** — каждый NPC, каждая локация, фракция, квест и событие помнят свою историю и отношения с игроком.

## 🚀 Быстрый старт

### Предварительно (на новой машине — один шаг)
```bat
scripts\setup_env.bat
```
Создаст `.env` из `.env.example` (впишешь API-ключи), поставит `requirements.txt` и поднимет
**свой** изолированный venv ChromaDB в `data/chroma-venv`. Дальше — только `start_game.bat`.

Окружение разработки (уже настроено):
1. **llama.cpp сервер** на `127.0.0.1:8080` (OpenAI-совместимый `/v1`) — модель `Ternary-Bonsai-8B-TQ2_0`.
2. **Python** `D:\Development\Development_Tools\Runtimes\Python\3.12.10\python.exe` (3.12.10, см. requirements.txt).
3. **Своя ChromaDB игры** в `data/chroma-venv`, поднята на `127.0.0.1:8001`.

### Запуск
```bat
start_game.bat
```
Он проверит llama.cpp, поднимет ChromaDB игры (если нет), запустит сервер на `http://127.0.0.1:8002` и откроет браузер. Если игра уже запущена — не запускает второй раз, а открывает её и показывает сообщение. При любой ошибке консоль не закрывается (ждёт Enter).

> 🔒 Сервер слушает **только 127.0.0.1**: в `.env` лежат живые API-ключи, а авторизации в игре нет.
> Нужен доступ из локальной сети — запускай вручную с `GAME_BIND=0.0.0.0`, на свой страх.

Первый запуск вручную:
```bash
# 1) ChromaDB игры (только если не запущена)
data/chroma-venv/Scripts/chroma.exe run --path data/chroma --host 127.0.0.1 --port 8001 --log-path data/logs/chroma.log

# 2) API — интерпретатор берётся из PATH (или укажи свой: set PY/GAME_PYTHON)
python -X utf8 -m uvicorn backend.app:app --host 127.0.0.1 --port 8002
```

Открой **http://127.0.0.1:8002** — выбери тему мира, рассказчика и играй.

> ⚠ Нужен конкретный интерпретатор (не тот, что в PATH) — задай переменную окружения
> `GAME_PYTHON=C:\путь\python.exe` (её же читает `start_game.bat`; Python 3.11+,
> см. `scripts/setup_env.bat`). Абсолютный путь в скрипты больше не зашит (сессия 38, D13).

> 📖 Для разработчиков/ИИ-агентов: **AGENT.md** (архитектура + правила разработки + инварианты),
> **AGENT_ARCHIVE.md** (хронология сессий 4–38: почему принято именно так) и **ROADMAP.md**
> (все идеи и статусы).

## 🎤 Рассказчик (сменные персоны)

В настройках мира или при создании мира можно выбрать рассказчика — персону, которая определяет стиль повествования:

- **8 предустановленных**: Классический ведущий, Строгий мастер, Поэт-сказитель, Наставник-попутчик, Шёпот ужаса, Ироничный циник, Режиссёр блокбастера, Летописец Системы. Они лежат **отдельными файлами** в `plots/narrators/*.js` (чистый JSON: `name`/`desc`/`prompt`) — править можно без перезапуска, движок подхватывает изменения (проверка mtime при GET /api/narrators, пересид в БД идемпотентно).
- **Сюжет может рекомендовать рассказчика**: в JSON сюжета укажи поле `narrator` (имя пресета) — при выборе этого сюжета в «Новый мир» рассказчик подставится в селект автоматически, но игрок всегда может сменить его на другого.
- Кнопка «Создать / править рассказчиков» в настройках: свой промпт (характер и стиль), изменение и удаление существующих (нельзя удалить того, кто уже ведёт мир).

## 🔊 Озвучка (TTS) — ответы рассказчика звучат

Ответы рассказчика можно **озвучивать** — у сообщений появится кнопка 🔊. Провайдеры:

| Провайдер | Что это | Русский | Примечание |
|-----------|---------|---------|------------|
| **Edge** ⭐ (рекоменд.) | облачный Microsoft Edge TTS | ✅ Svetlana / Dmitry Neural (очень естественные) | бесплатно, нужен интернет |
| **Piper** | локальный нейро-TTS через sherpa-onnx | ✅ ru_RU-ruslan / irina / dmitri / denis | работает без интернета, быстрее реального времени на CPU; голос скачивается один раз (~30–70 МБ); качество среднее (роботизированный) |
| **Kokoro** | локальный Kokoro-82M | ❌ (англ. и др.) | ~350 МБ, для англоязычных миров |
| **Выключено** | — | — | игра работает как раньше |

**Как включить:**
1. Настройки мира → «🔊 Озвучка» → галка «Озвучивать ответы рассказчика» → выбери провайдера и голос → «💾 Применить озвучку» → «🔊 Проверить голос».
2. Если голос Piper не скачан — нажми «⬇ Скачать голос» (интернет нужен один раз).
3. Глобальные настройки по умолчанию — в админке (`⚙ Админка` → «🔊 Озвучка») или `.env` (`TTS_*`).

**Поведение:** кнопка **🔊** у каждого ответа рассказчика (⏸ — остановить/продолжить, ⟳ — синтез готовится, ⚠ — ошибка/повторить). Галка «Автоматически проигрывать новые ответы» включает автопроигрывание. Аудио кэшируется — повтор одинаковых фраз не пересинтезируется. Синтез идёт в фоне и не замедляет игру.

> Установка с нуля: `scripts/setup_tts.bat` (ставит sherpa-onnx + edge-tts и скачивает русский голос Piper).

## 🔌 Провайдеры (настройки мира)

В настройках мира можно выбрать провайдеров для всех трёх служб:

| Служба | Провайдеры |
|--------|-----------|
| Основная модель (LLM) | llama.cpp (локально, 8080) · Ollama (локально) · OpenAI-совместимый API (RouterAI и др.) |
| Эмбеддинги (память RAG) | RouterAI (`qwen/qwen3-embedding-8b`) · OpenAI-совместимый · Локальный FastEmbed (оффлайн, ru+en) · Выключено |
| Реранкер | RouterAI (`voyageai/rerank-2.5`) · OpenAI-совместимый · Выключено (+ галка «Использовать реранкер») |

API-ключи в интерфейсе скрываются; пустое поле ключа = «не менять». Если выключить эмбеддинги/реранкер — игра продолжает работать, просто память деградирует до локального поиска (BM25). Все настройки — per-world, глобальные значения живут в `.env`.

## 🧠 Как устроена память (не теряем ничего)

| Слой | Что хранит | Где |
|------|-----------|-----|
| **Краткосрочная** | последние не-свёрнутые обмены в пределах бюджета мира (≈ контекст − оверхед − ответ; при контексте 32k это десятки тысяч токенов) | SQLite `events` (роль `player/narrator`) |
| **Сводки** | каждые N ходов старые события сворачиваются в 2–5-предложенную сводку (LLM) | SQLite `events` (роль `summary`) |
| **Векторная память** | ВСЕ обмены и сводки + карточки сущностей индексируются (эмбеддинги `qwen/qwen3-embedding-8b`, 4096-dim) и извлекаются по семантике (гибрид BM25+косинус + облачный реранкер `voyageai/rerank-2.5`) | **свой** экземпляр ChromaDB `:8001` |
| **Карточки сущностей** | каждый NPC/локация/фракция/квест/предмет/событие: `summary` (статус), `relationship` (отношения с игроком), `bio` (накопленная история), `meta` (alive/location/faction). Имя карточки — человекочитаемое, а не внутренний id (сессия 40, п.9) | SQLite `entities` + Chroma |
| **Карточки знаний** | созданные расы/классы/профессии/навыки/эффекты (бонусы, пассивки, баффы, ранги, стаки, моды) — рассказчик не противоречит себе | SQLite `entities` + Chroma |
| **Состояние мира** | механическое состояние: HP/MP, инвентарь, золото, квесты, враги, NPC, флаги, погода, время, локации. Герой живёт в «Игрок»: раздел NPC — только окружение, а не сам игрок (сессия 40, п.13) | SQLite `worlds.setting` |

**Процесс хода:**
1. Отбираются релевантные карточки (живые NPC рядом, текущая локация, активные квесты, упомянутые в действии) → в промпт.
2. RAG-поиск по памяти → релевантные обмены/сводки → в промпт. **Количество вспоминаемых фактов растёт с размером контекста мира**: при 32k — база (4 памяти + 3 лора), при 128k/256k — до 24 фактов памяти и 12 лор-чанков (потолки настраиваются в Админке 🧠 и per-world ползунками в Настройках).
3. Рассказчик генерирует ответ, механика передаётся блоком `<<ENGINE>>{...}` (кубы, урон, предметы, квесты, NPC, локации, флаги).
4. После хода (в фоне): обмен индексируется в Chroma; LLM-архивариус обновляет карточки (новые факты, отношения, статусы); при переполнении окна — сводка.

> 🛡 Если ответ рассказчика оборвался на полуслове или зациклился повтором (иногда так делает модель в tools-режиме), игра **автоматически дописывает завершение** и убирает подряд идущие дубликаты — в чате не остаётся обрезанных «груде кам».

## 🎲 Механики

- **Статы (7)**: сила, ловкость, выносливость, интеллект, мудрость, харизма, удача — влияют на проверки (рассказчик даёт бонус к кубу за профильный стат), повышаются/понижаются (`player.stats`), производные HP/MP пересчитываются от статов.
- **Раса**: 8 вшитых (человек/эльф/дварф/орк/зверолюд/полудемон/драконид/нежить — бонусы статов + пассивка) + творческие (укажи имя, `bonus`, `passive`).
- **Класс и ранги**: Воин/Лучник/Маг/Вор/Жрец/Бард (стартовый навык при смене) + творческие; ранги F→E→…→ZZZ→G, эволюция класса, мультикласс.
- **Профессии**: Кузнец/Алхимик/Травник/Охотник/Шахтёр/Повар/Портной/Моряк/Книжник — постоянный бафф стата + творческие (`buff`). **Профессии растут от действий**: дела (ковка, зелья, травы…) копятся в `player.actions`, но **смена профессии решает рассказчик** (директива `profession`) — авто-смена по порогу отключена.
- **Скрытые классы/расы/профессии**: выдаются за особые цепочки действий, ритуалы и испытания; условия получения сохраняются в карточках знаний.
- **Навыки с рангами**: `{имя: {rank, kind, desc, mp_cost}}`, улучшение рангов (skill_add/skill_rank), обучение/забывание.
- **Эффекты**: постоянные и временные (turns), стаки (урон ×стаки каждый ход), моды к статам (отображаются в «Характеристиках» с учётом эффектов), автотик в начале хода.
- **Кубы**: `d20`, `d100`, `2d6+1` — бросок при риске, результат описывается отдельным проходом рассказчика.
- **Бой**: урон (HP), враги `enemy_add/enemy_apply`, смерть, состояния.
- **Инвентарь/золото/опыт**: `add_item/remove_item`, `gold`, `xp`. Уровень растёт **только по сюжету** — директива `player.level` (автопрокачки по XP нет; рассказчик сам решает, когда прокачать).
- **Магазины и торговля**: рассказчик открывает лавки (`shop_add`), покупаешь (`price`), продаёшь (`value`); цены зависят от твоей репутации у фракции магазина (±5%/ед., потолок ±50%). **Вес рюкзака**: предметы могут весить; загрузка ограничена вместимостью от статов (сила+выносливость), и при перегрузе покупку/сбор/создание откажут («🎒 Перегруз») — следи за весом и разгружайся, продавая лишнее.
- **Крафт**: собирай ресурсы, учи рецепты (рассказчик через `craft`/`gather`) и создавай предметы/экипировку. Многие рецепты требуют **станцию** (кузницу, верстак, лабораторию — их у локации задаёт мастер) и/или **профессию**: без подходящего места/ремесла создать не выйдет — найди мастерскую или прокачай ремесло. У врагов и NPC может быть **кошелёк** (🪙) — при победе или убийстве их монеты переходят тебе.
- **Квесты**: `quest` (создание/прогресс), ветвление/ступени (`quest_advance` по `steps`, `quest_choose` по ветке), цепочки `quest_done {id, next}` (действие 1→2→3).
- **NPC**: жив/мёртв, настроение, фракция.
- **Фракции и репутация**: у фракции есть ступень доверия игрока (Изгой/Заклятый враг/Враг/Недоверие/Нейтрально/Доверие/Друг/Союзник) — NPC фракции реагируют по ней: дают уникальные квесты/секреты/скидки на высоких ступенях, отказывают, выдают или атакуют на низких. Фракции и их связи (союз/враг) заводит рассказчик (`faction_add`); изменение репутации «перетекает» на союзников и врагов фракции. Ступень видна в «Состоянии» и в профиле NPC.
- **Динамическая сложность**: сила врагов автоматически подстраивается под твой уровень (`enemy_add` HP/урон масштабируются движком; на 1-м уровне изменения нет), а частота случайных событий мира растёт с уровнем — мир усложняется по мере прокачки. Рассказчик задаёт «нормальную для локации» базовую силу врага, движок сам усиливает её.
- **Локации**: `location_add`, `move`.
- **Погода и время суток**: `weather`, `time`. Время/погода дают **геймплейные эффекты** (ночь снижает видимость/+скрытность, туман/гроза/буря/мороз влияют на проверки и передвижение) — показывается «Влияние среды» и учитывается рассказчиком в кубах. **Часы мира идут сами** (`AUTO_TIME_ENABLED`, `AUTO_TIME_EVERY`): каждые N ходов движок меняет время суток по циклу утро→день→вечер→ночь и пишет «🕐 Часы мира: …» — иначе вечер из сюжета залипал бы навсегда и противоречил расписаниям NPC. Погоду авто-часы не трогают (решение мастера); если погода не менялась несколько ходов, в состоянии появляется «⚠ Погода не менялась N ходов» — залипший туман иначе превращает весь текст в один повтор.
- **Расписания NPC**: у NPC можно задать `schedule` (`npc_set` с `{время: действие}`) — таверна ночью закрыта, рынок работает днём; отображается в сайдбаре у живых NPC.
- **Сверхспособности** (`ability_add/ability_use/...`): универсальные умения под любой жанр — заклинания, техно-устройства, псионика, навыки Системы (школа, источник, трата энергии MP).
- **Статистика и достижения**: автоподсчёт убийств/квестов/открытых локаций, `/stats`, 🏆 достижения (`achievement_add`).
- **Флаги** — любые факты о мире (дверь открыта, ловушка сработала и т.д.).
- **⏳ Таймеры мира**: дедлайны (бомба, осада, прибытие курьера) — движок сам тикает их в начале каждого хода и напомнит «⏰ Таймер истёк»; что произойдёт — решает рассказчик (`timer_add`).
- **⚔️ Экипировка и слоты**: у предметов может быть слот (голова/торс/руки/ноги/оружие/вторая рука/аксессуар) и бонусы к статам — надевай (`equip`/`unequip`), бонусы учитываются в характеристиках; два предмета в один слот не надеть.
- **🍖 Потребности и 🧠 рассудок**: голод/жажда/усталость и рассудок/стресс/мораль тикают сами по ходам; на критическом уровне мир предупредит — что делать, решает рассказчик.
- **📅 Календарь и сезоны**: время года влияет на проверки (зима — холод, лето — жара); праздники и сроки — сюжетные крючки.
- **⛰ Локации-зоны**: некоторые места (радиация, ядовитый туман, проклятие) действуют на игрока, пока он там — войти и выйти.
- **📜 Доска объявлений**: таверна/форум/рация — читай `/board` в любой момент.
- **🏅 Звания во фракциях**: репутация — доверие, звание — должность (Мастер-кузнец гильдии и т.п.).
- **🌙 Сны/видения**: мастер может разыграть видение при отдыхе — прошлое возвращается как сюжет.
- **🎲 Ставки на бросок**: рассказчик может объявить, что на кону при проверке.
- **Перегенерация ответа (↻)** — откат происходит по снапшоту, эффекты не задваиваются.
## 🗺 Карта мира, живые события и быстрые действия
- **Вкладка «Карта»**: открытые локации как граф; рёбра запоминаются автоматически при переходах (`move`) и при создании локаций рассказчиком (`location_add` с `connections`). Клик по соседнему узлу — отправить действие «идти туда»; по дальней локации — подсветить путь; фильтры «только достижимые»/«подписи». **Карта читается из графовой БД** (`/api/worlds/{id}/graph` — узлы (тип и признак текущего), рёбра, слои BFS, кратчайший путь; кроме локаций граф включает маркеры сущностей — магазины/фракции/живых NPC).
- **Вкладка «Лор»**: «библия» вселенной — большие статьи о мире (история, системы, фракции, термины). Добавляй/правь сам; рассказчик получает через RAG актуальное и релевантное (а не всё сразу), с сохранением канона. У миров по произведениям (Фантазия, Айнкрад, Ключи Пангеи, Хризалида — единый мир с эпохой «Безграничного») лор создаётся автоматически при создании мира; у «Своего сюжета» — из поля «Лор мира» (опционально).
- **Динамические события**: шанс случайного события (нападение, погода, NPC, находка…) растёт с каждым твоим ходом (`p = ходы/EVENT_EVERY_TURNS`), но событие никогда не гарантировано (потолок 0.5) — только шанс, без «расписания». Таймер по реальному времени убран — пока ты offline, мир не «живёт» сам. Событие записывается системным сообщением и меняет состояние. Выключается `DYNAMIC_EVENTS_ENABLED=false` в `.env`.
- **Автономный «мастер»**: если игрок «застрял» (долго повторяет одно действие или бродит без активных квестов), фоново появляется «🤖 Мастер: …» — квест или сюжетный поворот, выводящий из тупика. Вмешивается редко и только при реальном застое; выключается `AUTONOMOUS_MASTER_ENABLED=false`.
- **Боевой ИИ врагов**: пока в бою есть живые враги, они получают собственный тактический ход («⚔️ …») — преследуют, обороняются, отступают, пытаются договориться или ставят ловушку, с оглядкой на твой стиль и силы. Урон тебе ведёт рассказчик (ИИ не задваивает, не лечит/не призывает врагов); выключить — `ENEMY_AI_ENABLED=false`.
- **Варианты действий**: после каждого ответа рассказчик предлагает 3–4 ситуационных действия («бытовые», от первого лица) кнопками под полем ввода — кликни или напиши своё как обычно. Если ИИ не ответил — подставляются бытовые заготовки от состояния (соседние локации, NPC, квесты). Кнопки **не сбрасываются** при сбое генератора: прошлые ИИ-предложения остаются, пока сервер не пришлёт свежие по новой сцене.

## ✨ Что добавилось (сессия 34)

- **⏪ Перемотка назад**: кнопка «⏪ Назад к ходу» (или `POST /api/worlds/{id}/rewind`) возвращает мир
  к началу любого хода: состояние, недавнюю память и дневник. Ходы после точки удаляются
  (или сокрываются при загрузке сохранения). Векторы отменённых ходов вычищаются из памяти —
  рассказчик не вспоминает того, чего уже не было.
- **📔 Дневник приключений** (вкладка «Дневник» / `/journal`): авто-хроника значимого —
  новые квесты и их итог, первые встречи, находки, смены роли, новые места, истёкшие сроки.
  Детерминированно (без LLM). Своя заметка — `/journal note <текст>`. Клик по записи — к событию в логе:
  ранние страницы чата догружаются сами, а если хода в логе уже нет (перемотка/`↻`) — открывается
  ближайший сохранившийся с внятным объяснением (сессия 40, п.10).
- **🧭 Мои средства** (`/risk <идея>` или кнопка): справка «чем персонаж может закрыть затею» —
  профильные статы, навыки, вещи, станции, репутация, вес рюкзака. Чистый форматировщик
  состояния, без LLM и без вердиктов — решает рассказчик.
- **🏹 Ружья Чехова**: в состоянии появляется «🏹 На горизонте» — то, что введено в мир и с тех пор
  не звучало. Хороший повод вернуть деталь в сюжет; но это не обязанность — список гаснет сам.
- **🗝 Тайны NPC**: у персонажей есть заметки мастера (`npc_set {notes: {знает, тайна, хочет, долг}}`) —
  что он знает и скрывает. Подача игроку — намёками, через проверки и репутацию (правило 35).
- **⚔️ Статусы на врагах и тактика**: `enemy_effect_add` (горение/страх) и `enemy_mark` (позиция/
  инициатива/цель) — подсказки для боя. Статусы **не тикают сами**: урон врагам ведёт рассказчик
  своим `enemy_apply` (иначе задвоился бы урон).
- **🏅 Итог квеста и срок**: `quest_success` / `quest_fail {id, reason, next}`; квесту можно дать
  дедлайн `quest {id, timer: {name, turns}}` — мир сам напомнит «срок вышел», а исход решает рассказчик.
- **🔴 Живой чат**: фоновые события (ход врага, подсказка мастера, истёкший таймер) приходят
  мгновенно через SSE; поллинг остаётся запасным.
- **🧭 Компас и часы**: под чатом — соседние локации кнопками («идти →»), в шапке мира — время/погода/сезон.
- **📊 Качество ответов**: в метриках (`/api/metrics`) видны «ответы, упёршиеся в лимит» и
  «оборванные на полуслове», средняя оценка релевантности памяти; в плашке «🧠 Память» — сила совпадений.
- **⚙️ Новая наблюдаемость**: JSON-лог `data/logs/game.log` (контекст хода), ретраи временных сбоев
  LLM/Chroma/облака, очередь фоновых агентов с приоритетом (игрок всегда первый), ярусы промпта

## 🔧 Стабильность (сессия 36 — исправлены 21 дефект аудита)

Поведение игры не изменилось, но закрыты риски, которые проявлялись на длинных
прохождениях, после рестарта сервера или при кривом выводе модели:

- **↻ Перегенерация после рестарта** больше не задваивает ход: события помечаются номером
  хода (`meta.turn`), и «замена последнего хода» работает даже с пустым in-memory реестром.
  На время перегенерации фоновые агенты (судья/мастер/боевой ИИ/события/видения) не пишут в
  мир, а перечитав состояние, отказываются от записи, если игрок успел сходить.
- **Механика больше не протекает в чат**: блок `<<ENGINE>>{…}` / `game_engine({…})`, вставленный
  моделью в середину абзаца, вырезается целиком, а проза до и после него остаётся. В живом
  стриме обрывок маркера («…идём к gam») тоже не показывается.
- **👁 Провидение нельзя фармить**: между воззваниями появился минимальный интервал
  (`DIVINE_COOLDOWN_TURNS=3`, сбрасывается в 0 в админке), Провидение по промпту чинит
  согласованность, а не выдаёт новую добычу, и каждая выдача ресурсов видна в логе.
  Первое воззвание в новом мире при этом доступно сразу (кулдаун не считает «ещё не звал»
  нулевым ходом).
- **Импорт мира из дампа** не даёт «сломанный мир»: недостающие поля персонажа достраиваются,
  битые строки журнала пропускаются с записью в лог, а не валят весь импорт.
- **Списки и карточки не разрастаются**: горячие пути (окно памяти, карточки сцены,
  обратная связь 👍/👎, пересборка памяти после импорта) читают БД ограниченным
  хвостом/страницами вместо всего лога; список миров считается одним SQL-запросом.
  Попутно найден и исправлен незаметный дефект: синхронизация карточек архивариуса в
  состояние мира писалась тремя блоками подряд, и поздние затирали ранние — квесты и NPC,
  заведённые рассказчиком через карточки, молча исчезали из «Состояния». Теперь правки
  копятся в одном объекте и сохраняются один раз.
- **Журнал метрик ротируется** (`METRICS_MAX_BYTES`, по умолчанию 4 МБ × 3 архива), а
  суммарные счётчики в `/api/metrics` переживают перезапуск (база берётся из журнала).
- **Тихие сбои стали видимыми** (правило 14): NameError в удалении карточки, недоступная
  таблица админки, «БД не отвечает» — всё пишется в лог; `db._run` больше не может висеть
  вечно (потолок ожидания + защита от само-блокировки).
- **Безопасность**: из дампа мира вырезаются ЛЮБЫЕ вложенные `api_key` (а не только в
  provider_settings), а тело ошибки провайдера в логах маскируется на случай эха ключа.
- **Мелочи UX**: кнопки «Быстрые действия» не залипают на устаревших ИИ-вариантах; поллинг
  озвучки не плодит таймеры; ключ сущности с апострофом (LLM вполне вернёт `don't`) не ломает
  модалку квеста/магазина/NPC; Edge-озвучка повторяется при 429 вместо ⚠; `start_game.bat`
  считает llama.cpp живым, если тот отвечает 401 (сервер с `--api-key`); при штатной остановке
  сервера соединение БД закрывается (на Windows файл больше не залочен).

## ⚙️ Настройки в `.env`

- `MAIN_PROVIDER` (`llamacpp`|`ollama`|`openai_compat`) + `MAIN_BASE_URL` (для openai_compat — базовый `/api/v1`, БЕЗ `/chat/completions` — llm.py добавляет сам) + `MAIN_API_KEY` + `MAIN_MODEL`.
- RouterAI — это OpenAI-совместимый API, поэтому для облака: `MAIN_PROVIDER=openai_compat`, `MAIN_BASE_URL=https://routerai.ru/api/v1`, `MAIN_MODEL=...` (пример: `upstage/solar-pro4`).
- `TTS_ENABLED / TTS_PROVIDER (piper|kokoro|edge|none) / TTS_VOICE / TTS_RATE / TTS_AUTO_PLAY / TTS_CACHE_* / TTS_MAX_CHARS` — озвучка рассказчика (глобальные дефолты; per-world — в настройках мира). **Стандарт: `TTS_PROVIDER=edge`, `TTS_VOICE=ru-RU-DmitryNeural` (Edge, мужской голос).**
- `EMBEDDING_PROVIDER` (`routerai`|`openai_compat`|`local`|`none`): `EMBEDDING_BASE_URL/API_KEY/MODEL` (`qwen/qwen3-embedding-8b`, 4096-dim) — RouterAI. **`local`** — оффлайн FastEmbed: `LOCAL_EMBEDDING_MODEL` (по умолч. `paraphrase-multilingual-MiniLM-L12-v2`, 384-dim), кэш `LOCAL_EMBEDDING_CACHE` (`data/fastembed`); не требует ключа/интернета. Chroma-коллекция при `local` — `text_game_memory_local` (разная размерность — разные коллекции).
- `HYBRID_WEIGHT_BM25` (дефолт 0.4) — вес BM25 в гибридном поиске памяти RAG (0 = только косинус Chroma, 1 = только BM25); правится в админке (🎛 Генерация → «Вес BM25 в гибридном поиске RAG»).
- `RERANK_PROVIDER` (`routerai`|`openai_compat`|`none`) + `RERANK_ENABLED` (глобальный выключатель): `RERANK_MODEL=voyageai/rerank-2.5`; `RERANK_BASE_URL` — базовый `/api/v1` (клиент сам добавляет `/rerank`).
- `CHROMA_HOST/PORT/COLLECTION` — **своя** ChromaDB: `127.0.0.1:8001`, коллекция `text_game_memory` (не конфликтует с py_docs:8000).
- `DEFAULT_TEMP / DEFAULT_TOP_P / MAX_TOKENS / CONTEXT_TOKENS` — генерация по умолчанию; стандарт `MAX_TOKENS=2000` (макс. длина ответа), `CONTEXT_TOKENS=32768` (32k) — стартовый размер контекста новых миров (память ≈ контекст − оверхед − ответ; под облачные модели). Регулируется per-world ползунками «Max токенов»/«Размер контекста» в настройках; ползунок и сохранение допускают до 262144 (256k) для моделей с широким окном (128k/256k), не превышай фактическое n_ctx своей модели (локальная llama.cpp = 8192 — для неё уменьшай контекст).
  - ⚠️ `MAX_TOKENS` относится **только к обычным ходам** (ответы рассказчика на твои действия). Длина **вступительной сцены** задаётся отдельным жёстким лимитом в коде (`generate_opening`, `OPENING_MAX_TOKENS = 2400`) и настройками мира не управляется — меняется только в `backend/character_generator.py::generate_opening`. Вступление никогда не показывается оборванным: незаконченный текст (нет конца фразы или ответ упёрся в лимит) перегенерируется, а при неудаче берётся последнее полное предложение либо завязка сюжета.
- `RECENT_TOKEN_BUDGET / SUMMARY_TOKEN_BUDGET / RAG_MEMORY_K / RAG_MEMORY_MAX / RAG_CANDIDATES` — параметры гибридной памяти (RECENT_TOKEN_BUDGET — запасной бюджет, когда у мира не задан контекст). **RAG-факты и лор растут с размером контекста мира** (база при 32k → пропорционально больше при 128k/256k, потолки RAG_MEMORY_MAX/LORE_RAG_K_MAX/LORE_TOKEN_BUDGET_MAX): с окном 256k рассказчик вспоминает до 24 фактов памяти и 12 лор-чанков, а не фиксированные 4+3. Правится в Админке (🧠 Память) и per-world ползунками в Настройках мира (0 = авто).
- `LORE_TOKEN_BUDGET (900) / LORE_TOKEN_BUDGET_MAX (4500) / LORE_RAG_K (3) / LORE_RAG_K_MAX (12)` — сколько лора («библии» мира) попадает в промпт: бюджет в токенах и число RAG-чанков; потолки при большом контексте.
- `LOGIC_JUDGE_ENABLED` (вкл по умолчанию) / `LOGIC_JUDGE_INTERVAL` (раз в N ходов, дефолт 3) — **судья логики**: фоновый LLM-проход после хода сверяет ответ рассказчика с критичными фактами мира (живые NPC, флаги). Ошибку не переписывает, а оборачивает в атмосферный сюжетный поворот «искажения реальности». Не замедляет игру. Per-world выключается в настройках мира (галкой «⚖️ Судья логики»).
- `AUTONOMOUS_MASTER_ENABLED` (вкл по умолчанию) / `AUTONOMOUS_MASTER_INTERVAL` (раз в N ходов, дефолт 6) — **автономный «мастер»**: когда игрок «застрял» (долго повторяет одно действие или бродит без активных квестов), фоново генерирует квест/сюжетный поворот/слух («🤖 Мастер: …»), выводит из тупика. Вмешивается редко и только при реальном застое; не блокирует ответ.
- `ENEMY_AI_ENABLED` (вкл по умолчанию) / `ENEMY_AI_INTERVAL` (раз в N ходов, дефолт 2) — **боевой ИИ врагов**: пока в бою есть живые враги, они фоново получают свой тактический ход (преследование/охрана/отступление/переговоры/ловушка) с оглядкой на стиль игрока. Не дублирует урон — тактику решает ИИ. Выключи, чтобы враги были «статичными мишенями».
- `TICK_EFFECTS_ENABLED` (вкл по умолчанию) — **авто-тик статус-эффектов**: статус-эффекты (яд/кровотечение/регенерация) тикают сами в начале каждого хода (урон/лечение × стаки, turns−1). Это «физический движок». Если хочешь, чтобы мастер сам вёл урон/лечение директивами `player.hp` — поставь `false`; эффекты перестанут тикать самостоятельно. Уровень и профессии код в любом случае не меняет (только директивами рассказчика).
- `BACKGROUND_TASKS_ENABLED` (вкл по умолчанию) — глобальный выключатель **фоновых задач памяти**: RAG-индексация обменов/сводок и карточки сущностей (LLM-архивариус). Выключи в админке (⚙ → «Фоновые задачи памяти»), если нужен быстрый/дешёвый режим — память перестанет углубляться (динамические события и судья логики управляются отдельными флагами).
- `MAX_ACTION_CHARS` (дефолт 640) — максимальная длина действия игрока в символах (защита от слишком длинного ввода, который ломает токен-бюджет).
- `DETECT_MODEL_CONTEXT=true` — 🔎 **авто-детект реального окна модели**. Игра спрашивает у модели её лимит контекста (llama.cpp — `/props`, Ollama — `/api/show`, OpenAI-совместимые — `context_length` в `/models`) и не даёт миру заявить окно больше: иначе ответы **молча обрезаются** (локальная llama.cpp = 8192 при стандарте 32k). Если лимит определить не удалось — ничего не подгоняется. Реальный потолок виден в настройках мира и возвращается в `gen_settings.context_limit`.
- `BACKUP_DB_ON_START=true` / `BACKUP_KEEP=10` — 💾 при каждом запуске сервера делается **согласованный снимок** `data/game.db` в `data/backups/` (SQLite Backup API — не copy, не рвёт ходы), старые снимки срезаются до `BACKUP_KEEP`. `game.db` в git не лежит — это страховка от потери долгого прохождения.
- `METRICS_PERSIST=true` / `METRICS_FILE=data/metrics.jsonl` / `METRICS_TAIL=500` — 📈 журнал метрик ходов на диске: статистика времени генерации, токенов и «повторов» больше **не обнуляется при перезапуске** сервера (`/api/metrics` достраивает окно из хвоста файла, а суммарные счётчики восстанавливаются из журнала).
- `METRICS_MAX_BYTES=4194304` — 🔄 ротация журнала метрик (сессия 36): `METRICS_TAIL` ограничивал только чтение, файл рос бесконечно. При переходе порога `metrics.jsonl` сдвигается в `.1/.2/.3`; `0` = ротация выключена.
- `DIVINE_COOLDOWN_TURNS=3` — 👁 минимальный интервал между воззваниями к Провидению (защита от «попросить у богов золото»; `0` = лимита нет, как раньше). Правится в админке (🎛 Фоновые агенты).

> 💡 **Админка и Настройки теперь покрывают все ключевые параметры**: провайдеры, генерация (температура/контекст), память (RAG/лор/бюджеты), фоновые агенты (судья/мастер/события/боевой ИИ/тик эффектов/тик потребностей/Провидение/длина действия), TTS (включая кэш) и 🗄 переносимость (авто-детект контекста модели, бэкап БД при старте, журнал метрик и его ротация). Раньше часть из них жила только в `.env`.
>
> ⚠️ «Сбросить всё к .env» в админке именно **удаляет** переопределения (кнопка шлёт список `reset`), а не выставляет тумблеры в `false` — раньше после сброса молча выключались судья логики, автономный мастер, боевой ИИ, события и озвучка (фикс сессии 33).
>
> ⚠️ **Сессия 36 (п.2)**: форма админки отправляет теперь **только изменённые** поля. Раньше каждое сохранение записывало текущие эффективные значения в переопределения, и новый дефолт из `.env`/кода до них уже не доставал (так, кулдаун Провидения 0 → 3 не применялся на живой базе). Если изменил(ся) дефолт и «не видно» результата — нажми «Сбросить всё к .env».

## 🎯 Философия дизайна (три закона игры)

> ⚖️ **Канон формулировок — `AGENT.md`, раздел «🏛 ТРИ ЗАКОНА АРХИТЕКТУРЫ»**; здесь те же законы сжато.
> Заголовки обязаны совпадать в обоих файлах — следит `test_three_laws_identical_in_docs` (C11:
> раньше формулировки и наборы справок в двух документах разошлись).

1. **ТОЛЬКО универсальные механики (для всех жанров и тем).**
   Код хранит общие абстракции (HP/MP, золото, уровень, статы, инвентарь, эффекты, время/погода, фракции/репутацию, квесты, магазины, крафт, компаньонов, врагов, способности). «Воин/Маг/эльф/Кузнец» — лишь вшитые **подсказки-справочники**; рассказчик может ввести любую творческую расу/класс/профессию, указав её бонусы/пассивки/баффы. Движок не «прибит» к фэнтези и работает одинаково в реал/техно/космосе/детективе.

2. **Общие базовые возможности для удобства, отображения и базовой логики.** Код даёт инструменты: состояние мира в промпте (`format_state`), справки-агрегаторы (`total_sell_value`, `can_craft`, `/economy` `/stats` `/map` `/inventory`), инфраструктуру веса/вместимости, парсинг кривых слов от модели. Всё это — отображение и проверка, а не решения за мастера.

3. **Код только ПРОВЕРЯЕТ возможность; мастер-рассказчик решает ВСЁ.**
   - Код — «судья возможностей»: не хватает золота/материалов/станции/профессии/веса → отказ с пояснением.
   - Прогресс персонажа — творчество рассказчика: профессия/класс/титул/уровень/статы меняются **только его директивами**, авто-прокачки по XP и счётчикам нет.
   - Рассказчик всегда может разрешить действие или «дофантазировать» мир — код не запрещает.
   - Проверка любой идеи: *«Код решает за мастера?»* — если да, преврати это в **проверку возможности**, а решение оставь мастеру.

Файл — чистый JSON по схеме `PLOTS.md` (расширение `.js`): лор, завязка, акты/главы/квесты, стартовое состояние (локации/NPC/магазины/фракции/флаги) применяются автоматически при создании мира. После добавления/правки файла жми «🔄 Обновить сюжеты» в окне «Новый мир» (или просто обнови страницу — движок сам проверяет файлы). Мир, созданный из сюжета, хранит снапшот — удаление/правка файла не трогает уже созданные миры.
- Ходы считаются по действиям игрока; сложность показывается по-русски (лёгкая/средняя/хардкор).
- Кнопка **↻** у ответа рассказчика — перегенерировать ответ на тот же ход; **👍/👎** влияют на стиль последующих ответов.

- 🗄 **Бэкап и перенос мира**: Настройки мира → «🗄 Полный дамп (JSON)» скачивает весь мир (состояние, все ходы, карточки, лор, слоты, карта) одним файлом; «📥 Импорт из дампа» поднимает его **новым** миром — хоть на другой машине. Ключи API в дамп не попадают. Плюс при каждом запуске `start_game.bat` автосохранение всей БД в `data/backups/` (keep 10).
- Сложность влияет на стартовое HP и инструкции рассказчику.
