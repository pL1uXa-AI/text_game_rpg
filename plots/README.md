# 📁 plots/ — сюжеты-миры (файлы сюжетов)

В этой папке лежат **стандартные и пользовательские сюжеты** текстовой RPG. Движок
читает их при старте и **подхватывает изменения без перезапуска** (кнопка
«🔄 Обновить сюжеты» на экране «Новый мир»; GET /api/themes тоже сам проверяет
изменения файлов).

## Структура

```
plots/
├── system/     — комплектные «стандартные» сюжеты, идущие с игрой
├── user/       — твои сюжеты (создаются/правятся свободно)
└── narrators/  — предустановленные рассказчики (персоны повествователя)
```

Каждый сюжет — **один файл** с расширением `.js`, внутри — **чистый JSON**
(без обёрток/`export`), по полной схеме из `PLOTS.md`. Пример — `system/pepel-kontrakta.js`.

## Рассказчики (plots/narrators/)

Предустановленные персоны рассказчиков лежат **отдельными файлами** в `plots/narrators/`.
Каждый файл — чистый JSON:

```json
{
  "name": "Имя рассказчика",
  "desc": "Краткое описание (для UI)",
  "prompt": "Персона/промпт рассказчика — как он ведёт игру"
}
```

- Движок сканирует папку при старте и при GET /api/narrators (проверка mtime).
- Новые/изменённые файлы перезасеиваются в БД идемпотентно (`INSERT OR IGNORE` по `name`).
- Уже созданные записи в БД и миры не трогаются (можно править файлы свободно).

## Как добавить свой сюжет

1. Открой PLOTS.md — там полная схема и промпт для ИИ-агента, придумывающего сюжеты.
2. Попроси агента вернуть один валидный JSON по разделам PLOTS.md.
3. Сохрани его в `plots/user/` с именем вида `мой-мир.js` и нажми «🔄 Обновить сюжеты».
   Или просто перезагрузи страницу — файл подтянется сам (проверка mtime на `/api/themes`).

## Правила id

- `id` берётся из поля `id` в JSON, если оно есть; иначе — из имени файла
  (транслитерация: `мой-мир.js` → `my_mir`).
- Если сюжет с тем же `id` лежит и в `system/`, и в `user/` — **пользовательский
  переопределяет** системный (удобно править комплектный сюжет под себя).

## Миры не зависят от файлов

- Мир, созданный из сюжета, копирует в свой `setting` снапшот темы
  (`_theme_snapshot`) и стартовое состояние (`starting_state`: локации/NPC/магазины/
  фракции/квесты/флаги/золото/инвентарь/время/погода) в момент создания.
- Поэтому удаление/правка файла сюжета **не трогает уже созданные миры** — они
  продолжают жить по тем данным, что были при создании.
